# Dutch game
As a quick proof of concept on how to use AI to quickly code, I created a set of games set to help me progress in Dutch. The set includes:

- Multiple choice — Given a Dutch word, pick the correct English meaning from 5 options (what you described)
- Reverse quiz — Given an English word, pick the correct Dutch translation
- Type the answer — No hints, just type the translation yourself (harder)
- Flashcard mode — See the word, think of the answer, then flip to reveal it and self-rate (like Anki)
- Speed round — Answer as many as you can in 60 seconds

CSV structure needed:
dutch,english,category,difficulty
hond,dog,animals,easy
rennen,to run,verbs,medium
